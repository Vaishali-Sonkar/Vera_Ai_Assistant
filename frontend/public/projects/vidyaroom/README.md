# VidyaRoom assets

The showcase currently uses files in `frontend/public/projects/`:

- landingpage.png
- teacher_dashboard.jpeg
- transcriptions.png
- notes.png
- quiz.png
- doc.pdf

Edit the `vidyaroom` object in `frontend/src/data/projects.js` to change paths,
slide order, or image descriptions. Public URLs start with `/projects/`.
Other uploaded images are available for future slides.

The PDF opens in an embedded browser viewer. Toolbar suppression depends on the browser;
public files remain retrievable. There are no custom download, print, or raw-file links.
